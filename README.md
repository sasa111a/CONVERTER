Как запустить (без установки чего-либо):

Откройте папку DWQDW, зажмите Shift и правой кнопкой мыши по пустому месту → «Открыть окно PowerShell здесь» (или откройте PowerShell и перейдите в папку: cd C:\Users\user\Desktop\DWQDW).
Выполните: powershell -ExecutionPolicy Bypass -File serve.ps1
Откройте в браузере http://localhost:8000/video-to-mp3.html.
Пока нужен конвертер — окно PowerShell должно оставаться открытым (сервер работает, пока оно не закрыто).
